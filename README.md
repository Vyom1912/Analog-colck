# 🕒 Analog Clock

A real-time analog clock with colored hour, minute and second hands, built with CSS transforms and JavaScript.

## ✨ Features

- Shows the **current local time**, updated every second
- Hour hand moves gradually with the minutes
- Color-coded hands (hour, minute, second)
- Clock numbers positioned with **CSS custom properties** and rotation

## 🛠️ Built With

- HTML5
- CSS3 (custom properties, transforms)
- JavaScript (Vanilla, Date API)
